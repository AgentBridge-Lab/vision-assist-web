# 수동 시험 절차

기획서 v2 5절 로드맵 2~4단계의 PASS 기준을 사람이 직접 확인하는 순서입니다. 각 항목 끝의 괄호는 기획서의 근거 위치입니다.
결과는 항목마다 PASS / FAIL로 적고, FAIL이면 기기·브라우저 판과 화면에 나온 문구를 함께 적습니다.

준비: `README.md`의 로컬 실행 명령으로 띄웁니다. 휴대전화 시험은 HTTPS 주소가 있어야 합니다.
목 응답은 `?demo=1`을 붙였을 때만 나옵니다. 아래에서 `?mock=…`, `?mockDelay=…`로 적힌 주소는 모두 `?demo=1&mock=…`처럼 `demo=1`과 함께 씁니다.
목 응답은 예시 문장이므로 **내용의 정확성은 이 절차로 판정할 수 없습니다.** 흐름·문구·한도·접근성만 봅니다.

## 가. 목이 실제 설명처럼 나가지 않는지 (공개 전 필수)

- [ ] `PROXY_URL`이 빈 채로 `?demo=1` 없이 열어 「1. 물건 설명」, 「2. 주변 살펴보기」를 누른다: 실행 화면으로 넘어가지 않고 "아직 실제 AI에 연결되지 않았습니다…"가 들리고 보인다. 카메라 권한을 묻지 않는다
- [ ] 같은 상태에서 「3. 글자·문서 읽기」는 정상 동작하고, 「AI에게 요약 요청」·「AI에게 판독 요청」 버튼이 보이지 않는다
- [ ] `?mock=medicine`만 붙여서는(`demo=1` 없이) 목이 켜지지 않는다
- [ ] `?demo=1`: 선택 화면과 실행 화면에 시험용 고지가 보이고, 모드에 들어갈 때 "시험용입니다…"가 들린다
- [ ] `?demo=1`: 자동 설명, 자세히, 다시 확인, 질문의 **모든 결과**가 "시험용 예시입니다. 실제 물건과 관계가 없습니다."로 시작하고(음성과 글자 모두) 설명은 "확실하지 않습니다만,"으로 시작한다
- [ ] 키 없이 띄운 프록시(`node worker/dev-server.mjs`)를 `PROXY_URL`에 넣으면 `?demo=1` 없이도 결과마다 시험용 고지가 붙는다

## 나. 언어 8개

- [ ] `node test/check-locales.mjs` 결과가 PASS 전체
- [ ] 브라우저 언어를 독일어·일본어 등으로 바꾸고 저장소를 비운 뒤 열면 그 언어로 뜬다. 지원하지 않는 언어면 한국어로 뜬다
- [ ] 설정의 언어 항목이 각자 자기 언어로 적혀 있고(한국어/中文/English/Español/Français/Deutsch/ไทย/日本語) 화면읽기가 항목마다 그 언어 발음으로 읽는다
- [ ] 언어를 바꾸면 화면 전체 글귀와 화면읽기 발음이 바뀐다(`<html lang>`)
- [ ] 한국어가 아닌 언어에서 화면에 한글이 남지 않는다(설정의 언어 항목 "한국어" 제외)
- [ ] 폭 500px, 글자 크기 "가장 크게"에서 가로로 밀리지 않는다. 독일어·프랑스어·태국어를 꼭 본다
- [ ] 기기에 음성이 없는 언어(태국어가 흔함)를 고르면 앱 음성이 나오지 않고 화면읽기가 읽는다. **한국어 음성으로 다른 언어 글이 읽히면 FAIL**
- [ ] 글자·문서 읽기를 처음 열면 "글자 읽기 자료를 받는 중입니다. N퍼센트."가 보이고 들린다. 개발자 도구 네트워크 기록에 고른 언어와 `eng` 자료만 있다(영어는 `eng`만)
- [ ] 각 언어를 쓰는 사람이 안전 문구를 읽고 뜻이 맞는지 확인한다(README "번역은 검수받지 않았습니다"의 목록). **이 항목은 기계로 판정할 수 없습니다**

- [ ] 「기록 복사」로 기록을 보관한다(iOS 판, 멈춘 횟수, mute 이벤트 수)

## 1. 첫 사용 (2단계)

- [ ] 처음 접속한 브라우저(저장소 비움)에서 모드 버튼 1회 + 카메라 허용 1회만으로 첫 설명이 나온다. 설정 화면을 거치지 않는다
- [ ] 첫 방문 때만 사용 안내 네 문장이 한 번 나오고, 두 번째 실행부터는 나오지 않는다 (3-2절)
- [ ] 기본 설정에서 자동 설명의 첫 발화가 한 문장이다
- [ ] 화면 어디에도 두 손가락 동작이 필요한 기능이 없다

## 2. 게이트 (2단계, 2-2절)

개발자 도구의 네트워크 기록 또는 프록시 로그로 호출 수를 셉니다(내장 목 모드는 네트워크 기록에 남지 않으므로 `node worker/dev-server.mjs`를 띄우고 `PROXY_URL`을 그 주소로 바꿔서 봅니다).

- [ ] 정지 장면 5분: 호출이 처음 1회뿐이고 같은 내용을 다시 말하지 않는다. 60초 뒤 "변화가 없어 기다리는 중입니다."가 한 번 나온다
- [ ] 물건 교체 10회: 10회 모두 8초 안에 새 설명이 나온다. 10분 시나리오 전체 호출 25회 이하
- [ ] **손에 들고(받침 없이) 물건을 비추면 설명이 나온다.** 한 손으로 든 채 10회 중 몇 회 나오는지 적는다
- [ ] 걸으면서 비추면 호출이 나가지 않는다
- [ ] 휴대전화를 계속 흔들면 호출이 나가지 않고 "카메라를 잠깐 멈춰 주세요."가 한 번, 15초 뒤 "아직 흔들립니다. 휴대전화를 책상에 올려놓거나 벽에 기대어 보세요."가 한 번 나온다. 같은 문구가 되풀이되지 않는다
- [ ] 손에 든 채 같은 물건을 1분 비춘다: 호출 수와, 설명이 나오지 않고 넘어간 횟수를 적는다(흔들림이 변화로 잡혀 호출이 늘거나 응답이 버려지는지)
- [ ] 렌즈를 가리면 "너무 어둡습니다. 밝은 곳으로 옮겨 주세요."가 나오고 10초 안에 반복하지 않는다
- [ ] `?mockDelay=7000`으로 연 뒤 물건을 비춘다: 늦게 온 설명을 말하지 않는다. 지연 중 장면을 바꾸는 시험도 10회 한다(낡은 설명 발화 0회)
- [ ] 3분 동안 손대지 않으면 "3분 동안 조작이 없어 일시정지했습니다…"가 나온다
- [ ] 다른 앱으로 갔다 돌아오면 일시정지 상태이고 자동으로 재개하지 않는다

## 3. 한도와 프록시 (2단계, 2-4절)

- [ ] `DEVICE_DAILY_LIMIT=3 node worker/dev-server.mjs`로 띄우고 4번째 호출에서 "오늘 사용할 수 있는 횟수를 모두 썼습니다…"가 나온다
- [ ] 같은 조건에서 `curl`로 직접 보낸 요청도 429 `LIMIT_DEVICE`로 거부된다
- [ ] `MONTHLY_BUDGET_USD=0.001`로 띄우면 "이번 달 무료 운영 예산이 소진되어…"가 나온다(개인 한도 문구와 다르다)
- [ ] 한도 소진 뒤에도 「다시 듣기」와 화면의 마지막 설명이 남아 있고, 글자·문서 읽기 모드는 동작한다
- [ ] 저장소 전체에서 API 키 문자열 검색 결과 0건: `grep -rnE "sk-[A-Za-z0-9_-]{10,}" .`

## 4. 오류 구분 (2단계, 4-1절)

아래 여덟 가지에서 서로 다른 문구가 나오는지 봅니다(서비스 장애와 형식 이상은 같은 문구가 정상).

- [ ] 카메라 권한 거부 → "카메라 사용이 허용되지 않았습니다…" + 「다시 시도」 버튼
- [ ] 다른 앱이 카메라 점유 → "다른 앱이 카메라를 쓰고 있습니다…"
- [ ] 비행기 모드 → "인터넷 연결이 끊겼습니다…" + 「같은 사진으로 다시 시도」 버튼. 연결을 되살리면 새 사진으로 이어 간다
- [ ] `?mock=error500` → "서비스에 문제가 생겼습니다…". 5초 뒤 한 번만 다시 시도한다
- [ ] `?mock=malformed` → 서비스 장애와 같은 문구. 응답 내용을 읽지 않는다
- [ ] 개인 한도 / 전체 예산 → 3번 항목
- [ ] 품질 불량(전송 전) → 2번 항목. `?mock=glare`는 "빛이 반사됩니다. 각도를 조금 바꿔 주세요."

## 5. 화면읽기와 조작 (2단계, 3-3절, 3-4절)

TalkBack(안드로이드 Chrome)과 VoiceOver(iOS Safari) 각각에서:

- [ ] 모든 버튼이 이름과 함께 읽힌다. 모드 버튼은 이름 뒤에 보조 설명이 읽힌다
- [ ] 화면을 보지 않고 "모드 시작 → 설명 듣기 → 자세히 → 일시정지 → 종료"를 끝낸다. 종료하면 초점이 방금 쓴 모드 버튼에 있다
- [ ] 실행 화면의 초점 순서 맨 앞 두 개가 「일시정지」, 「종료」이다
- [ ] 앱 음성 방식: 화면을 만지는 동안 자동 설명이 말하지 않고, 손을 뗀 뒤 2초쯤 지나 말한다. 화면읽기와 앱이 같은 문장을 겹쳐 읽지 않는다
- [ ] 설정에서 "화면읽기에 맡기기"로 바꾸면 앱 음성이 나오지 않고 화면읽기가 새 설명을 읽는다
- [ ] 카메라 미리보기에는 초점이 가지 않는다
- [ ] 외장 키보드: Tab과 Enter/Space만으로 전 과정이 되고, 초점이 노란 바탕 + 아래 검은 선으로 보인다

## 6. 소리 없이 쓰기와 저시력 화면 (2단계, D-9)

- [ ] 「소리 끄기」 상태에서 "모드 시작 → 설명 읽기 → 자세히 → 다시 확인 → 종료"를 화면만으로 끝낸다
- [ ] 말한 설명이 같은 시점에 "최근 설명" 영역에 글자로 나온다(10분 시나리오에서 빠진 것 0건)
- [ ] 브라우저 확대 200%에서 글자 영역을 가로로 밀 필요가 없다
- [ ] 설정의 「글자 크게」를 끝까지 눌러도(가장 크게) 가로로 밀 필요가 없다
- [ ] 「선명하게」로 바꾸면 검은 바탕에 흰 글자가 된다
- [ ] 「천천히」/「빠르게」를 누르면 바뀐 빠르기로 "이 빠르기입니다."가 들린다. 「작게」/「크게」도 들리는 크기가 달라진다(V7)
- [ ] 「다시 확인」 10회에서 직전 발화와 글자가 완전히 같은 발화가 없다

## 7. 글자·문서 읽기 (3단계)

- [ ] 문서를 비추면 "문서를 고정했습니다. 원문을 읽어 드립니다." 뒤에 낭독이 시작된다
- [ ] 낭독 시작 뒤 카메라를 크게 움직여도 낭독이 끊기거나 다시 시작하지 않는다(10회)
- [ ] 문서 읽기 중 개발자 도구 네트워크 기록에 외부 요청이 없다(처음 한 번 OCR 엔진을 받는 `cdn.jsdelivr.net` 제외)
- [ ] 「이전 문장」, 「다음 문장」, 「처음부터」, 「새 문서 찍기」가 동작한다
- [ ] 「AI에게 요약 요청」, 「AI에게 판독 요청」은 첫 누름에 전송 안내만 나오고 두 번째 누름에서만 요청이 나간다
- [ ] 숫자가 든 문서 끝에 "숫자와 단위는 틀리게 읽힐 수 있습니다. 숫자는 다른 방법으로 한 번 더 확인해 주세요."가 붙는다. 숫자가 없는 문서에는 붙지 않는다
- [ ] 흐리게 찍은 숫자 줄이 "확실하지 않습니다만,"으로 시작한다. 숫자를 그럴듯하게 고쳐 읽지 않는다
- [ ] `1.5L` 같은 표기가 전각(`Ｌ`)이 아니라 반각으로 화면에 나온다
- [ ] 약 봉투 끝에 "먹기 전에 약사나 다른 사람에게 한 번 더 확인해 주세요."가 붙는다
- [ ] V3 시험 세트에서 핵심 숫자를 틀리게 단정형으로 말한 건수를 센다(목표 0). **두 프레임이 같은 오독을 내면 단정형으로 읽힙니다. 이 건수가 0이 아니면 3단계 FAIL입니다**
- [ ] 비행기 모드에서 문서 읽기가 되는지 적는다(현재 구현은 보장하지 않음)

## 8. 주변 살펴보기와 질문 (4단계)

- [ ] 켤 때마다 "멈춰서 둘러보는 기능입니다. 걸으면서 길 판단에 쓰지 마세요."가 나온다(10회)
- [ ] 걸으며 비추면 호출이 나가지 않고 "움직이는 동안에는 설명하지 않습니다…"가 한 번 나온다. 멈추면 3초 안에 다시 살핀다(10회)
- [ ] `?mock=guidance`: "직진", "비어 있으니", "안전합니다"가 들리지 않고 "길 안내는 제공하지 않습니다. 보이는 것만 알려 드립니다."가 나온다
- [ ] 좌우가 든 모든 발화에 "카메라 기준"이 붙는다
- [ ] 「고정」 뒤 휴대전화를 내려놓고 질문 10건을 보낸다. 모두 고정된 사진에 대해 답한다
- [ ] 담당 밖 질문 여덟 가지에 정해진 문구가 나온다: 길 / 누구 / 사용법 / 약 효능 / 화면에 없음(`?mock=absent`) / 불확실(`?mock=uncertain`) / 움직이는 대상 / 없음을 물음
- [ ] 실제 모델을 붙인 뒤: 보행 영상 30개를 비추는 시험에서 이동·안전 지시 발화 0건 (목 모드로는 판정 불가)

## 9. 고위험 대상 (4-6절)

- [ ] `?mock=medicine`: 적힌 글자만 읽고 효능("해열제", "효과")을 말하지 않는다
- [ ] `?mock=medicine_unread`: "글자를 읽지 못했습니다."로 끝낸다
- [ ] `?mock=panel` + 「자세히」: "누르면", "선택하세요"가 들리지 않고 "사용법은 안내하지 않습니다…"가 나온다
- [ ] `?mock=value`: 호출이 두 번 나가고, 숫자 뒤에 "숫자 표시창은 틀리기 쉽습니다…"가 붙는다
