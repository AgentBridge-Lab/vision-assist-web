# 시각 보조 — 시각장애인용 무료 AI 시각보조 모바일 웹

명세서는 `../구현기획서_v2_20261115.md`, 디자인 값은 `docs/DESIGN_TOKENS.md`입니다. 이 폴더는 로드맵 2~4단계(물건 설명 + 프록시, 글자·문서 읽기, 주변 살펴보기 + 질문)의 구현입니다.

**지금 상태: 글자·문서 읽기만 실제로 동작합니다.** 기기 안에서 도는 OCR이라 프록시 없이도 쓸 수 있습니다.

물건 설명과 주변 살펴보기는 실제 AI(프록시)가 연결되기 전에는 **실행되지 않습니다.** `js/config.js`의 `PROXY_URL`이 비어 있으면 모드 버튼을 눌렀을 때 "아직 실제 AI에 연결되지 않았습니다…"를 말하고 화면에 쓴 뒤 멈춥니다. 실제 AI 모델은 아직 한 번도 호출하지 않았습니다.

### 목(시험용) 응답이 실제 설명처럼 나가지 않게 하는 장치

목 응답은 사진을 보지 않고 미리 적어 둔 예시를 돌려줍니다. 보이지 않는 사용자가 이것을 실제 설명으로 들으면 안 되므로 네 겹으로 막았습니다.

1. 프록시 주소가 없으면 물건·주변 모드는 실행하지 않습니다(`js/main.js`의 `startMode`, `js/api.js`의 `describe`).
2. 내장 목은 주소에 `?demo=1`이 있을 때만 켜집니다. 켜지면 선택 화면과 실행 화면에 시험용 고지가 계속 보이고, 모드에 들어갈 때 한 번, **결과가 나올 때마다 맨 앞에** "시험용 예시입니다. 실제 물건과 관계가 없습니다."를 음성과 글자로 붙입니다.
3. 목 응답의 확신 정도는 `certain`을 쓰지 않습니다. 모든 목 설명이 "확실하지 않습니다만,"으로 시작합니다.
4. 프록시가 목으로 답하면(키 없이 배포된 worker) 응답에 `mock: true`가 실리고, 프런트는 `?demo=1`이 없어도 2번의 결과별 고지를 붙입니다.

## 로컬 실행

```sh
cd app
python3 -m http.server 8931 --bind 127.0.0.1
# 브라우저에서 http://localhost:8931/ 를 엽니다
```

- 설치할 것이 없습니다. `index.html`을 파일로 직접 열면(`file://`) 동작하지 않습니다. ES 모듈과 카메라가 둘 다 `http://localhost` 또는 `https://`를 요구하기 때문입니다.
- 8931은 예시입니다. 이 Mac에서는 8765와 8787을 다른 프로세스가 쓰고 있었습니다.
- **휴대전화에서 열려면 HTTPS 주소가 필요합니다.** `http://192.168.x.x` 같은 주소에서는 브라우저가 카메라 접근 객체를 주지 않아 "이 브라우저에서는 카메라를 쓸 수 없습니다"가 나옵니다. HTTPS 배포는 사용자 승인이 필요합니다(아래 "승인 필요").

### 시험용 주소 인자

`?demo=1`이 있어야 동작합니다. 예: `http://localhost:8931/?demo=1&mock=medicine`

| 주소 (`?demo=1&` 뒤에 붙임) | 유발되는 것 |
|---|---|
| `mock=medicine` / `medicine_unread` | 약 봉투(원문 + 확인 문구) / 글자를 못 읽은 약 봉투 |
| `mock=panel` | 조작판(조작 지시가 든 문장이 걸러지는지) |
| `mock=value` | 숫자 표시창(두 프레임 대조) |
| `mock=guidance` | 이동·안전 지시가 든 응답(주변 살펴보기에서 걸러지는지) |
| `mock=glare` / `far` / `unknown` / `notnew` / `important` | 품질 문제 / 멀리 있는 글자 / 모름 / 새 정보 없음 / 고지서 |
| `mock=absent` / `uncertain` / `moving` / `absence` | 담당 밖·대상 유무 문구 |
| `mock=error500` / `malformed` | 서비스 장애 / 응답 형식 이상 |
| `mockDelay=20000` | 응답 지연(밀리초). 8초를 넘기면 네트워크 오류, 6초를 넘기면 낡은 응답 폐기 |

## 스택 — 기획서 v2 §1-4에서 바꾼 한 가지

기획서는 "프레임워크 없는 TypeScript + 정적 빌드"인데, **빌드 단계가 없는 순수 ES 모듈(.js)로 구현했습니다.**

- 이유: TypeScript 컴파일러를 쓰려면 `npm install`이 필요하고, 의존성 설치는 사용자 승인 사항입니다. 승인 전에도 브라우저에서 바로 열어 검증할 수 있어야 했습니다.
- 타입은 JSDoc 주석(`@typedef`, `@param`)으로 적었고 파일마다 `// @ts-check`를 달았습니다. 나중에 `.ts`로 옮길 때 주석을 타입 선언으로 바꾸면 됩니다.
- 프레임워크·빌드 도구·npm 패키지는 쓰지 않았습니다. 외부 의존은 CDN `<script>` 하나입니다: Tesseract.js **5.1.1**(무결성 해시 포함), 엔진 tesseract.js-core **5.1.1**, 한국어 데이터 @tesseract.js-data/kor **1.0.0**(4.0.0_best_int, 압축 약 1.6MB). 주소는 `index.html`과 `js/config.js`의 `OCR_*`에 고정했습니다.

| 모델 | 요청에 `lang`을 실어 보내고 worker의 지시문이 그 언어로 답하게 합니다. 목 글귀도 언어별로 있습니다(`worker/mock/<코드>.js`) |

### 번역은 검수받지 않았습니다

**한국어를 뺀 7개 언어는 기계 번역이며 원어민 검수를 받지 않았습니다.** `check-locales.mjs`가 보는 것은 키가 빠지지 않았는지, 한글이 섞이지 않았는지, 금지 표현 목록이 시험 문장에 걸리는지뿐입니다. 뜻이 맞는지, 자연스러운지는 아무도 확인하지 않았습니다.

특히 아래 문구가 잘못 옮겨졌으면 위험합니다. 해당 언어를 쓰는 분의 검토와 수정 제안을 기다립니다.

- `guide` 네 문장: 걸으면서 길 판단에 쓰지 말 것, 사진이 외부 AI로 가는 모드와 가지 않는 모드, 약·돈·날짜는 한 번 더 확인
- `rule.medicineClosing`, `rule.medicalValueClosing`, `rule.importantClosing`: 약·수치·중요 문서의 확인 권고
- `outOfScope.navigation`, `rule.navReplaced`, `status.startScene`: 길 안내를 하지 않는다는 문구
- `forbidden`과 `question`: 이동 지시·조작 지시·약 효능 문장을 걸러 내는 낱말 목록. 빠진 표현이 있으면 그 언어에서는 금지 문장이 그대로 읽힙니다
- `rule.unsurePrefix`, `fmt.seems`, `fmt.quote`: 읽은 것과 짐작한 것을 구분하는 문형

**설계 근거도 한국 사용자에 한정됩니다.** 기획서의 당사자 조사(전사본, 문헌, 국내 설문)는 한국 이용자를 대상으로 했고, 그나마 숙련된 상위층에 치우쳐 있습니다. 화면 구성, 한 문장 기본값, 5초·8초 간격, 문구의 어조가 다른 언어권 사용자에게 맞는지는 확인한 적이 없습니다. iOS 판정 페이지(`test/ios-speech-camera-repro.html`)와 문서는 한국어뿐입니다.

## 프록시

`js/config.js`의 `PROXY_URL`이 빈 문자열이면 물건 설명과 주변 살펴보기는 실행되지 않습니다. 여기에 `?demo=1`을 붙이면 **시험용 내장 목**이 켜집니다. 프런트가 `worker/worker.js`를 브라우저 안에서 직접 실행하므로 서버가 없어도 한도 집행과 오류 응답까지 같은 코드로 돕니다. 사진은 어디로도 전송되지 않습니다.

프록시를 따로 띄워 시험하려면:

```sh
node worker/dev-server.mjs                                 # http://localhost:8787, 목 응답
PORT=8799 DEVICE_DAILY_LIMIT=3 node worker/dev-server.mjs  # 포트·한도 바꿔 시험
curl http://localhost:8787/health                          # {"ok":true,"backend":"mock"}
```

그다음 `PROXY_URL`에 그 주소를 넣습니다.

- 한도(2-4절): 세션 40, 기기 일일 100, IP 일일 600, 월 예산 5달러(80%에서 기기 한도 40으로 축소, 100%에서 정지), 이미지 400KB. 일일 기준은 한국 시간 자정입니다. Cloudflare 무료 등급의 자체 한도는 UTC 자정에 초기화되므로 두 기준이 9시간 어긋납니다.
- 한도 계수 저장: `LIMITS` 바인딩(Durable Object, 클래스 `LimitCounter`)이 있으면 거기에, 없으면 메모리에 셉니다. **메모리 계수는 프로세스가 다시 뜨면 사라지므로 배포용이 아닙니다.**
- 실제 모델 호출은 `USE_OPENAI="1"`과 `OPENAI_API_KEY` 시크릿이 **둘 다** 있을 때만 켜집니다. 키는 코드에 없습니다.
- 배포할 때는 `ALLOWED_ORIGIN`을 프런트 주소로 좁히십시오. 기본값은 `*`입니다.

배포 설정 예시(파일로 만들지 않았습니다. 배포는 승인 사항입니다):

```toml
# wrangler.toml
name = "vision-assist-proxy"
main = "worker/worker.js"
compatibility_date = "2026-11-01"
[vars]
ALLOWED_ORIGIN = "https://프런트-주소"
MONTHLY_BUDGET_USD = "5"
[[durable_objects.bindings]]
name = "LIMITS"
class_name = "LimitCounter"
[[migrations]]
tag = "v1"
new_sqlite_classes = ["LimitCounter"]
```

## iOS 판정 페이지

`test/ios-speech-camera-repro.html`은 파일 하나로 끝나는 페이지입니다(외부 스크립트·통신 없음, 마이크 요청 없음). 카메라를 켜고 음성 합성을 20번 재생하면서, 매번 발화가 끝난 뒤 1초 동안 영상 프레임이 계속 들어오는지 셉니다. 화면에 PASS / FAIL / 판정 불가가 큰 글자로 나옵니다.

아이폰에서 열려면 HTTPS 주소에 올려야 합니다. 이 파일 하나만 아무 정적 호스팅에 올리면 됩니다(승인 필요). 올린 뒤의 조작은 버튼 두 번, 소요는 약 1분입니다.

| 첫 방문 사용 안내 | 화면에는 바로 보이고, 음성은 첫 모드 버튼을 누른 동작에 이어서 말함 | iOS는 사용자 동작 없이 음성을 시작할 수 없습니다(1-5절) |
| 다시 확인, 결론이 같을 때 | "다시 봐도 같게 보입니다. N번 다시 확인했습니다." | 횟수를 넣지 않으면 연속으로 눌렀을 때 직전 발화와 글자가 같아집니다 |
| 담당 밖 질문 | 길·신원·사용법·약 효능은 글자 맞추기로 먼저 걸러 호출 없이 답함 | 호출 비용이 없고 결과가 일정합니다. 놓친 질문은 응답의 `out_of_scope`와 출력 검사가 다시 거릅니다 |
| 지각 해시 | DCT 방식 64비트 | 기획서는 방식을 정하지 않았습니다. 센서 잡음에 덜 흔들리는 쪽을 골랐습니다 |
| 알림 영역 | 앱 음성일 때는 끄고, 화면읽기·글자만·소리 끄기일 때 켬 | 3-4절 표 그대로. 앱 음성과 화면읽기가 같은 문장을 겹쳐 읽지 않게 합니다 |
| 오류 발화 | 진행 중인 발화를 끊고 먼저 말함 | 첫 방문 안내(약 15초) 뒤로 밀리면 카메라 권한 오류를 늦게 알게 됩니다 |
| `[구현 초안]` 문구 | `js/phrases.js`에 표시 | 기획서에 문구가 없는 상태(고정 풀기, 새 문서, OCR 준비 중 등) |
| `[구현 가정]` 수치 | `js/config.js`에 표시 | 품질 문턱(밝기 35, 선명도 12), 움직임 문턱 6, 말 빠르기·음량 단계 등 |

## 구현하지 않은 것

- **기기 음성 목록이 비어 있는 브라우저**: 음성 유무를 `getVoices()`로 판정하므로, 목록을 늦게 주거나 아예 주지 않는 브라우저에서는 음성이 있어도 글자·화면읽기 방식으로 떨어집니다. 다른 언어 음성으로 읽히는 것보다 낫다고 보았으나 실기기 확인이 필요합니다.
- **OCR 자료 저장 방식**: Tesseract.js 5.1.1이 내려받기 주소를 하나만 받아서, 언어 자료를 직접 받아 Tesseract.js의 저장소(IndexedDB `keyval-store`)에 넣어 줍니다. 5.1.1 내부 규칙에 기댄 것이라 버전을 올릴 때 다시 확인해야 합니다. 저장소를 쓸 수 없는 브라우저에서는 고른 언어만 받고 영문 혼용 인식이 빠집니다.
- **봇 차단(Turnstile)**: 화면읽기 통과 여부가 V6에서 정해지기 전이라 넣지 않았습니다. 지금 방어선은 한도와 월 예산뿐입니다.
- **오프라인 문서 읽기**: OCR 엔진을 CDN에서 받으므로 서비스 워커 없이는 비행기 모드 동작(3단계 PASS 기준)을 보장하지 못합니다.
- **영상 시각은 흐르는데 화면만 검은 경우의 카메라 재연결**(1-5절 마지막 행): 지금은 "어둡습니다" 안내로 떨어집니다. V2 실기기 결과가 필요합니다.
- **Durable Object의 지난 계수 정리**: 날짜가 바뀐 뒤 첫 요청에서 한꺼번에 지웁니다. 별도 알람은 없습니다.
- 처리방침·사용 안내문(6단계 산출물), 브라우저별 카메라 권한 복구 문구(1단계 확인 사항).
